# Composition and data-state vocabulary

A simple method can be one panel. Pick a hierarchy for the actual scientific question, not an obligatory example architecture.

- Pipeline + zoom: keep the end-to-end path compact; expand only a mechanism whose detail matters. A baseline/proposed comparison uses the same grid only if requested or supported by evidence.
- Overview + mechanism panels: overview (a) carries the reading path; (b)/(c) explain distinct genuine contributions. Use flat, light panels for new designs; reference-specific shadows/bevels are preserved only for reproduction.
- Parallel streams: align comparable stages and reserve a corridor for fusion/long skips. Do not add a graph, waveform or second stream solely because an example has one.
- Stage grouping: containers show real processing boundaries; they do not replace a readable data flow.

## Meaningful shapes

- Operations: compact layer bars or rounded blocks; additions, products and gates: distinguishable operator circles.
- Tensors: cuboids/segmented bars with only verified dimensional progression. Tokens: striped tiles/sequences; masks: visible/hidden cells.
- Graph data: node-link snapshots of known topology. Covariance: matrices; temporal data: genuine or explicitly illustrative waveforms/window snapshots.
- Compression: tapered heads only when dimensions actually shrink. Diamonds mean actual decisions; cylinders mean actual storage.
- Text/edge annotations: borderless labels, not generic boxed nodes. Do not replace every data state with a rectangle containing a noun.

## Identity and semantic grammar

The same token/channel/window/branch keeps its color and ordering across stages. Masked and visible index sets are exact complements. Illustrative feature glyphs are not experimental measurements; never invent measured data, dimensions or topology.

Choose one functional palette, using only the families needed. Optional starting colors: projection=peach FBE5D7, normalization/gates=gold FFE699, convolution=sage E2F0D9, attention/wavelet=blue BDD7EF, metric/reduction=plum 7C5A74, manifold/tangent=olive 9E8D65, dense=forest 54813A or lavender B9C1EF. Define selected colors locally; dark fills need readable contrasting text. User-required strict journal/monochrome styling wins over this suggestion.

Primary forward/trainable flow is dark and solid; target/stop-gradient/loss input is neutral and labeled. New-design dashed projection/group boundaries should have one meaning, auxiliary feedback can be dotted, and long residual tracks normally stay solid with clear gaps. Journal defaults or an explicit user grammar can differ; don't mix meanings. Reproduction preserves the reference grammar.

Include a compact legend for unfamiliar symbols or branch colors. Keep overview hierarchy, typography, padding, projections and line width consistent. Do not flatten all operations into the overview or shrink labels to hide collisions.
