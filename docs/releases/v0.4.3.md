# AgenTikZ v0.4.3

## MCP 与 Agent

- 新增随桌面端打包的 Rust MCP 程序，提供 9 个画布查询与修改提案工具。
- 设置中支持管理、测试、导入导出外部 stdio / Streamable HTTP MCP 服务，并按 Agent 选择挂载。
- 敏感配置支持系统凭据或仅本次运行保存，导出时排除敏感值。
- 内置工具通过临时令牌访问本机回环桥接；请求绑定原始聊天、项目和画布，过期提案不能覆盖新源码。
- 支持停止 Agent 请求，以及明确启用完整本机访问和指定工作目录；默认仍限制原生文件与命令权限，画布修改仍须用户审核。

## TeX 预览与导出

- 改善常用宏、坐标表达式、曲线、旋转文字和作用域裁剪的兼容 SVG 预览。
- 完整 LaTeX 文档保留原始导言区与页面设置，并恢复旧版导出产生的重复文档包装。
- 真实 TeX 编译失败时保留诊断，兼容预览明确标注；忽略编辑前的过期编译结果。

## 打包

- ACP 适配器改为紧凑资源包，增加资源清单、内容哈希、隔离构建与打包保护测试。
- 桌面构建自动准备原生 MCP 程序，macOS universal 包含两个架构。
- 跨平台 CI 增加原生 MCP 握手、真实工具转发和结构化错误测试。

## 已知边界

- 外部 HTTP MCP 是否可用取决于 ACP Agent 的能力声明，连接测试成功不代表本轮已经调用。
- 外部 MCP 服务按自身权限运行，暂不提供逐工具拦截。
- 不支持的复杂 TikZ 语法仍需本机 TeX；生产构建仍有大 chunk 警告。

安装包、Web 静态包与 `SHA256SUMS.txt` 由 GitHub Actions 验证后发布。
