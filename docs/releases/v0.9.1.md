# AgenTikZ v0.9.1

## 编辑画布与精确预览并存

- 修复检测到宏、复杂路径、旋转文字等语法后直接隐藏编辑画布的问题。TeX 精确预览改为并排对照，保留可解析图元的选择、拖拽、文字编辑和源码入口。
- 对照预览可随时收起，包括编译过程中；编译完成后不会强制重新打开预览或改变编辑模式。
- 明确提示交互画布只显示受支持的语法子集，未解析源码原样保留。兼容 SVG 预览标注为近似，不冒充真实 TeX 输出。

## 完整文档字体与缺字检测

- 含中文、但尚未配置中文字体的完整 `.tex` 文档，会在编译副本中补入内置字体包。保留原有绘图语句、字体设置和文档结构，不重复嵌套导言区。
- 内置字体补齐混合文字标签中的直接输入希腊字母，如 `γ`，不改写原有数学公式。
- TeX 即使退出成功，也可能遗漏字体不支持的字符。现在检测缺字日志并明确报错，不再将文字不完整的图形发布为精确预览。
- 兼容预览保留彩色旋转文字及箭头颜色，避免整幅兼容预览因文字颜色选项而失效。

## 预览与导出使用同一份真实结果

- 桌面端 SVG/PNG 导出使用真实 TeX 编译得到的 SVG，与精确预览保持一致；正在编译时等待同一任务，不要求用户再次点击导出。
- 编译失败或存在缺字时，不再退回简化交互画布或兼容 SVG，避免悄悄丢失路径、文字和样式细节。
- 保留简单图形在浏览器中的画布导出；复杂图形的真实 TeX 编译仍需要桌面端。

## 回归测试与发布内容

- 补充编辑/预览并存、关闭预览、并发编译、过期结果、导出一致性及真实 TeX 字体回归测试。
- 仓库只加入最小通用回归样例，不包含用户提供的完整研究图纸。
- 忽略本地渲染输出、临时目录、覆盖率与浏览器测试报告，安装包继续由 GitHub Actions 验证、构建后发布。
- 测试发现范围限定为当前项目的 `src/`，防止已忽略的旧工作区被重复执行并干扰验证结果。
- 继续保留 v0.9.0 的独立 MCP 绘图服务、内置 Agent、TeX 引擎及官方论文模板。

## 当前边界

- 完整渲染验证通过不代表任意宏、坐标表达式或复杂路径都已支持逐图元鼠标编辑；此类内容仍可编辑源码并使用精确预览检查。
- 不修改用户已经明确配置的中文字体。自定义字体缺失或不覆盖所用字符时，会保留真实错误供用户处理。
