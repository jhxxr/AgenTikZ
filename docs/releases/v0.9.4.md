# AgenTikZ v0.9.4

## 按需绘图技能

- 新建、复刻和局部编辑不再把整套设计教程、色板和图元示例塞进每轮提示词。常驻内容只保留短规则和技能目录，正文由 `get_diagram_design_skill` 按需读取。
- 提供四个应用内技能：科研图设计、参考图复刻、画布局部编辑、投稿风格。旧主题和宏模板仍可按原接口读取。
- Pi、ACP 和外部 MCP 使用同一套工具，不启用外部技能市场或本机文件自动发现。

## 读取不再空转

- 第一次读取某技能的参考页时，同时返回该技能的工作流程。`workflow`、`.` 和 `SKILL.md` 都指向这个入口。
- 同一次请求里已经完整提供的页面不再重复返回正文。连续没有新内容时停止应用内请求，并说明原因；外部连接只收到错误，不会取消外部模型。
- 工具记录显示具体技能、参考页和页范围，而不是把所有读取都显示成同一条“查阅绘图规范”。
- 修复 Claude Code ACP 把工具名放在标题字段时，内置 MCP 调用被误判为本机权限请求的问题。

## 组件库

- `stage_box`、`mha_block`、`dl_block` 这类示例中的 TikZ 样式名可以找到对应组件。
- 未知 ID 返回可用组件列表，不再把这次查询记成失败。ID 存在但分类不匹配时仍会拒绝。

## 验证与发布内容

- 394 项前端测试通过，覆盖技能懒加载、重复页去重、ACP 工具名兼容和组件样式名查询。
- TypeScript/Vite 生产构建通过，固定提示词仍保持短预算，技能正文按页懒加载。
- MCP schema 测试通过。真实 ACP 验收确认简单图和单标签修改可以生成待审提案与真实预览；复杂参考图复刻仍可能在提案前超时，本次不把该场景标为已完成。
- Windows、macOS、Linux 安装包及 Web 静态包通过 GitHub Actions 验证后构建发布，并提供 SHA256 校验文件。
