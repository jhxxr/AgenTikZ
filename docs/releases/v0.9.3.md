# AgenTikZ v0.9.3

## 无限画布

- 移除固定纸张外框、画幅尺寸预设和纸张缩放手柄，网格铺满整个工作区。图元保留源码中的原始坐标，可自由放置在正、负坐标区域。
- 首次载入内容按原始比例居中；已有视角和后续编辑保留当前缩放与平移，避免导入或修改代码时反复压缩整图。
- 支持拖拽空白处、按住空格拖拽、中键拖拽及 Alt 拖拽平移。平移期间捕获指针，拖出画布后仍可正常结束操作。
- 滚轮围绕鼠标所在位置缩放；工具栏缩放围绕可见区域中心进行，支持 1%–800% 缩放，并提供恢复 100% 与查看全部内容按钮。
- 网格随视角平移、缩放并自动调整间距；对齐辅助线与期刊栏宽参考线覆盖可见区域。

## Fit 保留原始布局

- 修复 Fit 为了适应固定纸张而移动普通节点和图表、改写源码坐标的问题。现在 Fit 只调整视角，不修改图元位置、源码、选择状态或撤销历史。
- 查看全部内容时统一考虑节点、路径、宏组合、连线及图表，包含远离原点的内容与负坐标。
- 画布属性面板改为无限画布说明与查看全部内容操作，配图标签栏不再显示固定画幅尺寸。

## 验证与发布内容

- 369 项前端测试通过，覆盖鼠标锚点缩放、远距离与负坐标内容、混合路径和图表、源码与撤销历史保留，以及空画布视角。
- TypeScript/Vite 生产构建通过；浏览器验证缩放、空白区域拖拽平移及节点双击编辑。
- 保留原有节点、路径、宏实例、图表编辑、真实 TeX 预览和导出流程。
- Windows、macOS、Linux 安装包及 Web 静态包通过 GitHub Actions 验证后构建发布，并提供 SHA256 校验文件。
