# AgenTikZ v0.9.2

## 原画布中的路径与文字编辑

- 坐标路径、填充色块、圆角矩形、圆、折线、贝塞尔曲线和旋转文字接入原有 `InteractiveCanvas` 与 AST。选择、拖动、八向缩放、属性修改、复制、对齐、删除和撤销共用原有工具。
- 修复导入使用毫米、点、缩放基向量或负方向坐标轴的图形后，编辑画布空白或图元偏移的问题。画布统一使用物理坐标，修改时转换回对应源码。
- 保留路径绘制顺序、裁剪、颜色混合、文字锚点、旋转和箭头尺寸，路径控制点可在原画布中调整。
- 复杂语法不会自动把原画布切换为只能查看编译结果的模式；可解析内容继续在原画布编辑，其他源码原样保留。

## 宏实例、连线与源码回写

- 普通宏调用与有界 `foreach` 列表、范围作为组合图元进入原画布。支持实例移动、缩放、文字及参数编辑，保留共享宏定义。
- 实例变换回写到对应调用的作用域；重复拖动复用已有编辑作用域，避免不断嵌套。组合图元具有稳定边界名称，可通过原有连线工具连接。
- 为需要连接的匿名节点补充名称；复制宏实例时生成独立边界名称，移动后连线继续跟随。
- 节点、路径、图表及图片继续共用原有工作区操作。局部源码修改保留其他语句、注释和文档结构；独立 MCP 服务也能读取所选路径。
- 本次兼容扩展不修改 TeX 精确预览、导出和后端渲染逻辑，沿用 v0.9.1 的真实 TeX 输出与字体处理。

## 验证与发布内容

- 361 项前端测试及生产构建通过，补充物理坐标、路径样式、宏实例、连线、缩放、复制、源码保留、不同换行符和撤销回归测试。
- 使用包含 551 个图元的复杂图形，在原画布完成实际鼠标操作验证；生成的编辑源码通过内置 TeX 引擎编译。
- 仓库仅包含通用最小测试样例，不包含用户完整研究图纸、截图、编译输出或测试临时文件。
- Windows、macOS、Linux 安装包及 Web 静态包由 GitHub Actions 验证后构建发布，并提供 SHA256 校验文件。

## 当前支持范围

- 宏展开和循环解析设有边界，支持普通宏及简单有界循环。任意 TeX 程序、自定义包语义和复杂计算仍需通过源码编辑，并用精确预览检查。
- 宏与循环按调用实例作为组合编辑；展开后的内部图元不会被误当成独立原始语句回写。
