# AgenTikZ v0.7.0

## Pi 多渠道与自定义 API 接入

- 新增独立渠道管理：添加、命名、删除渠道，自定义 API 基础 URL；同一供应商和同一协议可配置多个渠道。
- 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Google Generative AI 四种 API 协议，兼容渠道不再受固定 SDK 模型目录限制。
- 每个渠道的 API Key 按独立 ID 保存到系统凭据库，不写入 localStorage、项目文件或命令行；删除渠道先删除对应凭据。
- 支持从渠道获取模型列表，搜索并勾选添加；也可手动输入模型 ID，或从 SDK 参考目录选择。获取列表不会覆盖已配置模型或自动恢复已删除模型。
- 可删除模型、设置各渠道默认模型，并核对图片输入、推理、上下文长度及最大输出长度；未知能力默认不猜测。
- 聊天面板可快速切换 Pi 渠道与模型。会话按渠道地址、协议、模型能力与密钥隔离，避免相同模型 ID 串用不同渠道。
- 模型列表请求使用认证头，不跟随重定向；支持有界分页、响应体与模型数量限制及超时，不回显服务端错误正文。

## ACP 连接后选择模型

- “连接 / 获取模型”会完成 ACP 初始化并创建不带提示词、不挂载 MCP 的探测会话，读取 Agent 实际提供的模型配置。
- 设置与聊天面板共用模型选择，按 Agent 保存偏好；不再仅检测 Initialize 后就把模型 API 当作已验证。
- 每轮发送前通过 `session/set_config_option` 实际切换并核对 Agent 确认的模型；失效、不支持或未确认时停止，不静默回退。
- 接收配置更新通知，刷新 Agent 最近确认的模型与选项。未提供模型选择能力的 Agent 继续使用自身默认模型。
- 为 Claude Code 的 `cross-format conversion does not support context_management` 提供明确渠道兼容性诊断：使用原生 Anthropic 上游，或在 Pi 配置渠道真实支持的协议。应用不会擅自移除该请求字段。

## 验证与使用边界

- 已通过前端构建、250 项前端测试、41 项 Rust 测试、21 项 Pi 测试、10 项适配器打包测试和 2 项原生 MCP 传输测试。
- 真实固定版本 Pi SDK 对接本地测试服务，验证四种 API 协议、不同渠道地址与密钥隔离；真实 ACP stdio 测试验证模型确认先于提示词，以及不支持和拒绝切换时停止。
- 浏览器交互检查覆盖渠道添加、模型添加/删除、渠道切换及默认模型恢复；未使用用户真实密钥或调用付费模型。
- 模型获取只验证列表接口，不保证推理请求成功。手动添加模型后需根据渠道规格核对能力；不同渠道的协议兼容性仍由实际服务决定。
- 桌面端仍需本机 Node.js 22.19+；真实 TeX 预览仍需 TeX Live 与 dvisvgm。Pi 不复用 CLI 订阅登录，不开放本机 shell 或第三方 MCP。

Windows、Linux、macOS 安装包、Web 静态包与 `SHA256SUMS.txt` 由 GitHub Actions 验证、构建成功后发布。
