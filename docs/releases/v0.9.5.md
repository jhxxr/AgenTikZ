# AgenTikZ v0.9.5

## 模型独立思考强度

- 将“思考强度”放入内置 Pi 的模型配置卡，按渠道与模型独立保存，不再让不同模型共用一个档位。
- 设置页、聊天快捷选择、连通性测试及实际请求使用对应模型的档位，切换模型时恢复其已保存的偏好。
- 保留默认、关闭、极低、低、中、高、超高和最大档位；模型或网关不支持特定推理参数时，可选择“默认（不传参数）”。
- 兼容旧版配置：已有模型未设置档位时继承原全局偏好；手动添加、渠道发现及 SDK 目录中的新模型默认使用 `auto`。
- 补齐 Rust IPC 字段、默认值和参数校验，密钥仍单独保存在系统凭据库。

## Agent 选择面板

- 弹窗根据触发按钮的位置和窗口尺寸定位，限制左右边距及最大高度，避免展开后超出主界面。
- 窗口缩放或页面滚动时重新定位，长内容在弹窗内滚动。
- Pi 渠道选择独占一行，模型与思考强度使用可收缩的双列布局，避免控件挤出面板。

## 验证与发布内容

- 增加旧配置迁移、模型独立偏好、请求档位及弹窗视口边界的回归测试。
- 前端全量测试、Pi 运行时测试和 TypeScript/Vite 生产构建验证；Rust 校验覆盖新增字段、旧配置默认值及非法档位。
- Windows、macOS、Linux 安装包及 Web 静态包由 GitHub Actions 完成验证和构建后发布，并提供 `SHA256SUMS.txt`。
