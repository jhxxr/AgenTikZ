# AgenTikZ v0.7.5

## 项目助手自动模式（默认开启）

- 右侧项目助手新增「自动模式」，新安装与尚未做过选择的现有设置默认开启。本轮成功结束后自动应用最终画布提案和论文修改集，生成与渲染期间不会提前改动内容。
- 自动应用仍检查画布版本、源码哈希以及论文修订号。内容已变化、请求报错、取消、中途关闭、切换项目或提案被拒绝时不会覆盖。已应用的修改可从原卡片撤回。
- 对 ACP Agent，自动模式同时放行本机文件读写和命令执行：优先单次授权，只有没有单次选项时才使用始终允许。内置 Pi 仍只能使用 AgenTikZ 项目工具。
- 手动关闭会被记住；设置重置后恢复为自动模式。运行中不能切换。

## 侧边协作面板

- 对话历史、重命名与删除、模型选择、技能菜单、画布或论文差异审核集中在同一侧栏，不再把运行状态和确认操作分散到多个区域。

## 使用边界

- 自动模式会允许受信任的 ACP Agent 访问本机文件并执行命令。只应对信任的本地 Agent 保持开启。
- 密钥仅保存在系统安全凭据库或当前进程会话中，绝不写入任何配置文件、项目文件或版本仓库。
- 安装包与校验码由 GitHub Actions 自动化构建后发布。
