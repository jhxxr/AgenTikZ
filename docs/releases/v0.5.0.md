# AgenTikZ v0.5.0

## 项目级 Agent：从配图延伸到论文

- 绘图和论文共用 Agent 面板，同一项目切换工作区不丢失对话。
- 新增项目上下文、读取未保存论文章节、多文件修改提案和真实编译诊断工具；内置 MCP 工具增至 13 个。
- 论文修改支持逐文件 Diff、整组应用、拒绝与撤回，使用版本/hash 检查保护后续手动编辑。
- 论文预览与 Agent 共用编译状态，配图或正文变化会使旧编译结果过期。

## 可选内置 Pi SDK

- 内置固定版本 Pi SDK 1.5.0，不需要安装 Pi CLI；原有 ACP/BYOA 后端继续保留。
- 正常多轮任务保留真实工具历史；支持项目与会话隔离、任务停止、运行时重置以及推理强度选择。
- 模型 API Key 保存在系统凭据库，不进入项目、前端设置或命令行参数；模型服务独立计费，不复用 ACP CLI 登录。
- Pi 仅开放 AgenTikZ 项目工具，不加载个人扩展、第三方 MCP、原生 shell 或任意文件写入工具。
- 增加任务 turn、时间、输出大小和会话缓存边界；失败时明确重建会话，不模拟成功。

## 更可靠的图片 → 论文链路

- 素材卡片明确区分加入画布与插入论文，弹窗预选对应素材；可直接导入 PDF/PNG/JPEG。
- 选图或刷新不会清空手填图注、标签；插入后定位到实际论文源码。
- 外部图片不再顺带保存画布或生成 TikZ 宏包；空章节不会被整篇论文模板替换。
- 修复重复插入、标签冲突、错误光标位置、缺失主文件、未转义路径和非法宽度处理。
- 保存失败、图源同步失败或磁盘图片缺失时不再提示成功；脏编辑保留供重试。
- 修复生成图片登记接口参数不匹配和默认文件名反复覆盖；保存路径与 PNG 真实尺寸校验贯通。
- 同名导入自动改名，并保护并发导入、素材刷新及跨项目的异步结果。
- 项目切换时撤销旧画布自动保存定时器，避免延迟任务作用于新项目。
- 移除空画布中央的“从你的想法开始绘图”引导框。

## 环境与已知边界

- **Node.js 最低版本提升至 22.19.0**。安装包携带 Pi SDK 资源，但不携带 Node 可执行文件。
- Pi SDK 当前保留完整依赖资源，约增加 109 MiB 未压缩资源；这与既有精简 ACP 适配器分开打包。
- Pi 会话保存在当前应用进程内存中；取消、重置、切换项目、退出或超时后只恢复可见聊天，不声称恢复旧工具历史。
- 真实 TeX 编译仍需桌面端与 TeX Live。SVG/WebP 直接用于论文前需转换；完整 LaTeX 文档不能直接当作 TikZ 片段嵌入。
- 插入/编译成功不等于科学内容或视觉效果已经核实。草稿编译沙盒、视觉审查和全自动修复循环尚未接入。
- 本地验收覆盖前后端测试、真实 Pi SDK 的本机模型服务集成和浏览器交互；未使用付费图片/模型服务或执行真实 TeX 论文编译。

跨平台安装包、Web 静态包与 `SHA256SUMS.txt` 由 GitHub Actions 验证、构建成功后发布。
