# AgenTikZ v0.7.2

## 第三方 API 网关与混合思考模型兼容性强化

- **API 基础地址智能规范化**：支持用户粘贴裸域名、带末尾斜杠或完整端点后缀的网关地址，自动按协议解析（OpenAI 自动规范化为 `/v1`，Anthropic 剥离重复的 `/v1/messages`，Gemini 补全 `/v1beta`），彻底解决网关 404 与协议路径错位问题。
- **DeepSeek V4.1 混合思考优化**：针对第三方 OpenAI 兼容网关自动启用 `thinkingFormat: 'deepseek'` 与兼容参数。当关闭推理时显式发送 `thinking: { type: "disabled" }`，消除服务端长隐藏思考令牌消耗，实测单轮响应速度由 26.7s 提升至 3.6s（提升 7.5 倍），避免 27k+ 字符绘图上下文超时及 `finish_reason: "length"` 截断；默认输出 tokens 提升至 32768。
- **代理与 TLS 证书链保留**：在 Pi 子进程环境重置时完整保留 `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY` 以及自定义 CA 证书环境变量（`SSL_CERT_FILE`、`NODE_EXTRA_CA_CERTS`），并自动将 `127.0.0.1` 合并入回环豁免名单，确保本机 MCP 工具桥接正常通信。
- **LaTeX 提案自动规范化与反斜杠恢复**：为 `propose_tikz_patch` 增加源码容错与标准化处理，自动剥离外层 Markdown 代码块围栏与独立 `\documentclass` 导言区（保留局部宏定义与颜色），自动恢复由于 JSON 单斜杠误转义丢失的 `\begin`、`\footnotesize`、`\tikzset` 等关键 LaTeX 反斜杠，并在嵌套 `tikzpicture` 时给出针对性的 `scope` 改写指导。
- **布局修复防覆盖冲突保护**：为 `propose_layout_repair` 支持可选的 `proposalId` 参数，在 `inspect_layout_diagnostics` 返回体中明确标注检查目标（`pending_proposal` 或 `live_canvas`），避免智能体在生成新图后误用空白旧画布覆盖待审提案；在长驻会话续轮中自动附带当前画布最新的版本号与 hash。
- **系统凭据与非多模态体验优化**：在无 OS 密钥环服务的 Linux/WSL 环境中提供进程内存凭据兜底；对纯文本模型动态关闭 `render_canvas_preview` 引导，并提供分级故障诊断与中文排查建议。

  - 27k 字符复杂双流架构图首轮生成并一次性成功挂载提案；
  - 40k 字符上下文第二轮多轮增量修改成功复用长驻会话并完成外科手术式补丁；
  - 推理流式问答平稳运行。
- `runtime/pi` 单元/集成测试 24 项全部通过；Vitest 前端测试 25 个文件、253 项用例全部通过；`tsc -b && vite build` 生产构建零警告零错误。
- `agentikz-mcp` Rust 测试全部通过。

## 使用边界

- 密钥仅保存在系统安全凭据库或当前进程会话中，绝不写入任何配置文件、项目文件或版本仓库。
- 桌面端仍需本机 Node.js 22.19+；更新安装包后需重启应用。
- 安装包与校验码由 GitHub Actions 自动化构建后发布。
