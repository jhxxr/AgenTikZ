# AgenTikZ v0.4.2

本次为运行时性能与可靠性补丁，不改变项目文档格式。

## 性能优化

- 使用单次构建的源码行索引，避免每个 AST span 都从文件头扫描。
- 同机纯节点样例中，1000 节点完整解析中位耗时由约 465 ms 降至 3–4 ms；该基准不代表端到端帧率。
- 优化批量坐标补丁、节点查找和排序，减少拖拽过程中的重复工作。
- 缩小 React 状态订阅范围，并缓存不变的 LaTeX 标签组件，减少无关重绘。

## 可靠性修复

- 同文件保存串行化、相同内容并发保存去重，不同文件仍可并行保存。
- 修复保存期间编辑导致脏状态误清除，以及切换项目后的旧缓存和异步回调污染。
- 切换项目、编译论文和论文模式下 Ctrl+S 会保存全部待保存的论文文件。
- 修复论文入口参数名不匹配；编译前保存论文、画布和配图宏。
- 为 TeX/BibTeX 子进程增加超时，忽略过期编译结果，并防止旧 PDF 被误判为本次编译成功。
- 修复预览在编辑、主题切换、撤销和图像资源加载后的失效与同步逻辑。

## 验证与已知边界

- 本地通过 89 项前端测试、14 项 Rust 测试和生产构建。
- 浏览器冒烟检查覆盖模板渲染、内置预览、论文同屏，以及模拟桌面桥接的入口参数和过期结果处理。
- 尚未执行真实 TeX Live 整篇论文编译的端到端验证。
- 生产构建仍有大 chunk 警告，后续再独立处理按需加载。

安装包和 Web 静态包由 GitHub Actions 跨平台构建，`SHA256SUMS.txt` 提供校验值。
