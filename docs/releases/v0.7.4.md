# AgenTikZ v0.7.4

> v0.7.3 因自动发版校验未通过而没有发布安装包，本版本包含 v0.7.3 的全部内容，并修复了导致校验失败的 Node.js 版本识别问题。

## Node.js 预发布版本识别修复

- 修复内置 Pi 的 Node.js 版本检查会把带预发布或构建后缀的版本（如 `v22.19.0-rc.1`、nightly 构建）误判为不受支持的问题；此前使用这类 Node.js 的用户会看到「需要 Node.js 20.12 或更新版本」而无法启动内置 Pi。

## 内置 Pi 桌面端稳定性修复、双端思考强度可选与实时运行动画

- **内置 Pi 与 ACP 双端「思考强度」自由选择**：
  - 内置 Pi 新增 `默认（不传参数，由模型/网关决定）`（`auto`，默认选中）及 `off` / `minimal` / `low` / `medium` / `high` / `xhigh` / `max` 共 8 档思考强度，在右侧协作面板顶栏与设置页双向同步；默认档位不携带额外推理参数，避免不支持推理参数或档位受限的模型/第三方网关返回 `HTTP 400`，同时完整保留流式推理内容展示与多轮工具回放。
  - 修复自定义网关下 DeepSeek 系列模型推理参数映射，补齐 `xhigh` / `max` 档位透传，支持按需开启深度思考或高速直出。
  - ACP 自动发现并展示本机 Agent（如 `codex-acp`、`claude-agent-acp`、`opencode`）声明的 `thought_level` / `effort` 思考强度选项，模型不支持所选档位时给出清晰的可用档位中文提示。
- **实时思考动画、阶段进度与耗时计时器**：
  - 右侧 Agent 协作面板新增实时活动状态卡片（加载旋转动画、三点跳动波浪、`mm:ss` 实时计时器、行内一键「停止」按钮、自动展开的流式「Agent 思考与推理过程」字数统计面板以及工具执行中徽章），消除长思考或复杂绘图生成时的无反馈等待感。
- **桌面端内置 Pi 启动与代理容错根因修复**：
  - 自动规范化 Windows 常见无协议前缀代理（如 `127.0.0.1:7890` → `http://127.0.0.1:7890`），拦截并提示不支持的 `socks5://` 代理，强制本地回环直连 `NO_PROXY` 保护 MCP 桥接，并在未显式开启软件代理且本地代理软件关闭时自动忽略失效回环端口。
  - 放宽 Node.js 运行时兼容范围至 `>=20.12.0`（补齐 `Promise.withResolvers` 与 `zlib.createZstdDecompress` 兼容守卫，并遍历系统 `PATH` 自动优选高版本 Node）。
  - `worker.mjs` 直接加载无头 SDK 子模块，彻底解除对 `pi-tui` 与原生剪贴板插件的运行时依赖；打包体积精简约 60%（文件数从约 29,871 降至 6,083）。
- **渠道配置体验与一键连通性探测**：
  - 设置页新增「测试模型连通性」按钮，自动保存未提交的 URL / API Key / 模型草稿并按当前所选思考强度实测网关延迟；模型列表支持空格模糊搜索与一键「选用」；历史 `4096` 输出上限配置自动迁移至 `32768` 并支持超长输出自动续写。

## 使用边界

- 密钥仅保存在系统安全凭据库或当前进程会话中，绝不写入任何配置文件、项目文件或版本仓库。
- 桌面端内置 Pi 需本机安装 Node.js 20.12+（推荐 22 LTS）。
- 安装包与校验码由 GitHub Actions 自动化构建后发布。
