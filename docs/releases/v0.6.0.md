# AgenTikZ v0.6.0

## 让 Agent 能查看真实成图

- 新增 `render_canvas_preview`：编译当前画布或待审提案，将真实 TeX 渲染以原生 PNG 图片块返回给 Pi / ACP，并附带布局诊断。
- 绘图对话默认提供“生成提案 → 渲染看图 → 按图修正”的视觉复核指引；提案卡片可展开查看同一份真实预览。
- 每轮最多渲染 3 个不同输入，相同源码、主题和编译配置复用结果；失败也保留真实诊断，避免重复空转。
- 渲染结束后重新检查请求、画布版本、提案和编译配置，取消或过期结果不会回填。
- 预览不应用修改，最终仍需人工审核。界面明确区分源码布局评分、真实预览和 Agent 的视觉检查结论。

## Agent 对话支持粘贴图片

- 支持 Ctrl+V 粘贴截图、选择 PNG / JPEG / WebP、缩略图预览、移除和仅图片发送。
- 每条消息最多 4 张图片，每张原图不超过 10 MB；发送前自动缩放和压缩。
- 参考图以原生图片消息传递给模型，渲染图以原生图片工具结果传递，不把 base64 当作普通对话文本。
- ACP 检查图片输入能力，并在后续请求中携带最近最多 4 张参考图。Pi 正常会话只发送本轮新图，重建会话时补发最近参考图。
- 普通文字粘贴、Shift+Enter 换行与中文输入法回车保持可用。

## 内置论文绘图设计 skill

- Pi 和 ACP 绘图任务共用用户提供的 `tikz-diagram-reproduction`：先规划视觉叙事，再选择图形、语义色板和箭头语法。
- 支持总览与局部展开、并行流对齐、数据形态演进、token / mask 身份连续性，以及图结构、张量、时序与流形表达。
- 原始设计指南、四组论文宏模板和测量脚本随项目保留；通过新增 `get_diagram_design_skill` 按主题和行号读取参考，不逐轮注入完整模板库。
- 原创图可使用局部定义的功能语义色板；明确要求严格期刊或黑白风格时按用户要求约束。
- 复刻任务记录 `% @diagram-design` 意图，保护参考图的颜色、比例、布局、标签和线型，避免自动精修覆盖。
- 菱形、梯形、圆柱、自定义文字颜色及复杂宏/路径采用真实 TeX 预览，避免画布把非标准形状误显示为普通矩形。
- 内置 MCP 工具增至 15 个。

## 环境与验证边界

- 真实预览需要桌面端、本地 TeX Live 与 dvisvgm；图片理解需要支持视觉的 Agent / 模型。安装包不附带 TeX Live，Node.js 仍需 22.19 或更新版本。
- 图片会发送给用户选择的 Agent / 模型服务；会话和参考图当前保存在应用内存中。
- 复杂路径、宏和部分 PGF 形状不承诺逐个节点可拖拽；真实渲染结果以 TeX 为准。
- 原 skill 的 Python 测量脚本作为参考保留，未注册为 Agent 执行工具，不声称做过未执行的像素测量。
- 已完成前端、Rust、真实 Pi SDK 本机模型接口与原生 MCP 传输测试及浏览器交互检查；未使用真实模型做成图质量对比，也未实跑本地 TeX 与真实模型的完整修图闭环。

Windows、Linux、macOS 安装包、Web 静态包与 `SHA256SUMS.txt` 由 GitHub Actions 验证、构建成功后发布。
