# AgenTikZ v0.8.0

## 内置 TeX 编译：不再需要安装 TeX Live

- 桌面版随应用分发 Tectonic 0.17.0（XeTeX 内核），TikZ 精确预览与论文 PDF 编译统一使用内置引擎。移除系统 TeX Live / MiKTeX / MacTeX 路径配置、安装扫描与命令回退。
- 默认引擎为 XeLaTeX（Tectonic）。编译按钮新增下拉菜单，提供「强制重新编译」「清理后重新编译」「清理中间产物」。LuaLaTeX 和 pdfLaTeX 尚未内置，菜单会明确标为不可用，不会用别的引擎冒充。
- TikZ 图形先编译为 PDF，再由应用内的 Rust 转换器生成纯路径 SVG。文字与公式转为轮廓，不依赖系统字体或额外安装 dvisvgm。
- 内置 Noto Sans CJK SC Regular / Bold 开源中文字体，使用应用随附的字体包处理中英混排。
- 预置 fontspec、xeCJK、TikZ、PGFPlots、tikz-3dplot、pgf-blur、xcolor、standalone、geometry、preview、varwidth、amsmath、mathtools、amssymb、bm 等常用宏包，以及内置官方论文模板所需的依赖。常用文档可离线编译；未预置的宏包首次使用时联网下载，之后本地缓存。
- 论文中间产物放在 `.agentikz/build/`；清理操作保留论文源码与导出的 PDF。普通编译会检查源码是否变化，强制编译可完整重跑。
- SyncTeX 正反向定位由 Rust 直接读取映射，不再依赖系统 `synctex` 命令。

## 官方论文作者包与模板库

- 用官方作者包原件替换此前的通用 `article` 仿制格式，内置 IEEEtran、NeurIPS 2026、ICML 2026、ICLR 2027、CVPR / ICCV、ACL / EMNLP，以及空白论文。
- 官方模板保持原有样式、示例、参考文献、图片与目录结构；标题和作者请在主文件中修改。Nature 科研配色主题继续保留，但不再作为官方论文模板展示。
- 新增「新建论文 → 导入模板」，支持本地文件夹、ZIP / TAR / TAR.GZ、压缩包 URL（含无扩展名下载接口）及公开 HTTP(S) Git 仓库。
- GitHub、GitLab、Gitee 仓库使用压缩包下载，不要求安装 Git；其它 Git 服务通过本机 Git 安全克隆。支持指定子目录、多主文件手动选择、模板删除及内置引擎试编译。
- 模板保存在应用数据目录，可跨项目复用。删除模板不会影响已经创建的论文。
- 记住模板真实主文件与专属目录，正确打开 `example_paper.tex`、`neurips_2026.tex`、`sec/` 等，不再强制假定入口叫 `main.tex`。
- 导入默认只下载、解包和识别文件，不运行仓库脚本或自动编译。试编译须手动启动或明确勾选；只对可信来源使用。
- 导入限制文件数量与总大小，拒绝路径穿越、Windows 特殊路径和重复归档成员，防止目录链接将写入重定向到项目之外。

## 验证与使用边界

- 前端 280 个测试与 Rust 68 个测试通过；Rust 验证包含真实 GitHub 导入、隔离 HTTPS Git 克隆、无扩展名 URL、嵌套主文件和内置引擎实际编译。
- 在 Windows 桌面应用中实测 ICML 官方模板创建并生成 7 页 PDF，以及 GitHub ACL 模板导入和试编译。
- 官方作者包通常面向 pdfLaTeX。内置 XeTeX 内核已能编译这些模板，但正式投稿前应使用会议要求的工具链复核版式。ECCV 2026 的 `axessibility` 依赖与当前内置引擎不兼容，暂未内置。
- 当前远程导入仅支持公开 HTTP(S) 来源，不支持 SSH 或私有仓库登录。分支名含 `/` 时，请使用明确的压缩包下载链接。
- Tectonic 的主内存上限为编译期固定值，不能通过 `texmf.cnf` 调整。超大热力图或极多节点的单图可改用 PGFPlots `matrix plot` 或拆分子图。
- 浏览器版不含原生 TeX 引擎与桌面模板库，只提供空白论文预览；完整编译与模板导入请使用桌面版。
- 跨平台安装包和 SHA-256 校验码由 GitHub Actions 校验、构建后发布。
