# AgenTikZ v0.8.1

## 自动模式：边写边改，无需确认

- 修复项目助手自动模式仍需等待整轮结束才应用修改的问题。ACP 和内置 Pi 共用即时应用链路，每次完整且有效的 `propose_*` 工具修改立即更新画布或论文编辑器，无需点击确认。
- 连续修改基于最新源码、修订号和哈希继续执行，拒绝过期请求覆盖用户后续编辑；中途开启自动模式不会追溯授权旧请求。
- 同一轮的连续自动修改保留累计差异和原始内容，结束后可从修改卡片整组撤回。运行中暂停撤回，避免与后续工具修改竞争。
- 停止或错误不会回滚此前已经成功应用的修改；修改仍保留在编辑器中，并可在本轮结束后撤回。

## 真实预览与工具状态

- `render_canvas_preview` 支持检查待审核提案和已自动应用的配图；渲染本身不修改源码，继续保留版本检查、每轮最多三次不同渲染及相同输入缓存。
- 工具结果返回实际 `status` / `applied` 和最新版本信息。统一 ACP、Pi、MCP 工具说明与侧栏提示，避免把工具调用成功误认为已保存或编译。
- 修复只有工具修改、没有文本回复的 ACP 请求在自动应用后未被识别为有效提案的问题。
- 补充即时应用、连续修改、冲突拦截、视觉预览和错误或取消后撤回的回归测试。

## 使用边界

- 手动审核模式仍保留预览、确认、拒绝和撤回；自动模式仍执行版本与来源检查。
- 自动应用到编辑器不等于保存或编译成功。论文沿用现有自动保存链路，图形编译成功也不代表完成视觉检查。
- ACP 自动模式允许受信任的本地 Agent 读写文件和执行命令；Pi 仍仅使用 AgenTikZ 项目工具。
- 继续包含 v0.8.0 的内置 TeX 引擎、中文字体、常用宏包和官方论文模板库。
- 跨平台安装包与 SHA-256 校验码由 GitHub Actions 验证、构建后发布。
