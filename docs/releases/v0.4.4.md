# AgenTikZ v0.4.4

## 独立论文工作区

- 论文与绘图独立切换，移除“论文 + 画布同屏”模式。新建论文、打开章节和插入配图不再自动打开绘图画布、属性面板或绘图助手。
- 论文区提供文件树、大纲、CodeMirror 源码编辑器与可调整宽度的 PDF 预览。
- 简化新建项目界面，保留空白论文、Nature、NeurIPS、CVPR、IEEE 与 arXiv 写作起点。期刊/会议选项是通用 article 起点，不是官方投稿样式。
- 新论文不再附带示例绘图、缺失的配图引用或虚构的实验数据。

## 源码与 PDF 双向定位

- 分隔线旁新增源码 → PDF、PDF → 源码定位按钮；支持跨章节跳转与 PDF 位置高亮。
- 支持 `Ctrl/⌘ + 点击 PDF` 返回对应源码行。
- 桌面端论文编译启用 `-synctex=1`，使用 TeX 安装目录中的 `synctex` 执行真实定位。
- 内嵌 PDF.js 预览提供多页浏览、缩放与适应宽度；PDF 通过受项目边界限制的二进制接口读取。
- 源码修改后需重新编译，旧映射不会继续用于定位。浏览器模式不模拟本地编译。

## 绘图界面清理

- 删除整图模板库、构图缩略图、模板载入器与 AI 整图模板引用逻辑。
- 保留基础绘图组件、PGFPlots 组件、期刊配色和已有绘图文件的编辑能力；新画布从空白开始。
- 保留论文配图插入面板与 LaTeX 图注、引用标签、单栏/跨栏配置，插入后留在论文区。

## 环境与边界

- Node.js 最低版本调整为 22.13.0。
- 真实论文编译与双向定位需要桌面端、TeX 引擎和 `synctex`，请在 TeX 设置中配置对应的 bin 目录。
- 本地验证包含真实 PDF 渲染、模拟桌面接口的双向定位检查及前后端自动化测试；本地环境未检测到 TeX，未执行真实 TeX 编译到定位的完整端到端测试。
- 当前插图通过面板引用项目素材；暂不支持直接粘贴截图或拖入图片即插入论文。
- 生产构建仍有大 chunk 提示；PDF 预览按需加载。

安装包、Web 静态包与 `SHA256SUMS.txt` 由 GitHub Actions 验证后发布。
