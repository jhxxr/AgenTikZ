# AgenTikZ v0.9.6

## 交互画布解析

- 支持在 `tikzpicture` 内定义颜色和样式，包括 `\definecolor`、`\colorlet`、`\tikzset`、`.style` 和 `.append style`，以及 `thick` 等常用线宽选项。
- 修复复杂图中箭头、残差连线、虚线框和彩色外框丢失的问题。样式按顺序应用，离开 `scope` 后恢复外层样式。
- 遇到无法解析的语句时，保留原始源码并继续解析其余图元。画布标出失败行号，完整效果仍以 TeX 预览为准。

## 验证与发布内容

- Transformer 回归图在浏览器画布渲染 40 个节点与 54 条路径；故意破坏一条路径后，其他 53 条路径仍可显示。
- Windows、macOS、Linux 安装包及 Web 静态包由 GitHub Actions 构建发布，并提供 `SHA256SUMS.txt`。
