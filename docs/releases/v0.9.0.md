# AgenTikZ v0.9.0

## 让其他 Agent 通过 MCP 操作 AgenTikZ

- 新增独立 **MCP Server** 接入：外部 Agent 软件 → MCP stdio → AgenTikZ 当前画布。不需要在软件内发送聊天消息、启动 ACP/Pi Agent 或配置模型 API Key。
- **设置 → MCP 服务 → 让外部 Agent 操作 AgenTikZ** 提供开启/关闭、访问权限和连接配置复制；外部客户端使用打包的原生 `agentikz-mcp` 程序连接。
- 原“为应用内 Agent 添加第三方 MCP 服务”的功能保留在高级折叠区，明确区分两个调用方向。

## 11 个绘图工具与三种权限

- 支持读取真实源码、AST 和选区，获取绘图组件、主题配色和设计参考，检查布局，以及完整重绘、精确局部修改和布局修复。
- **只读检查**拒绝修改；**修改需审核（默认）**显示源码 Diff，用户可应用或拒绝；**直接修改画布**即时应用通过版本检查的修改，保留逐次撤销记录并沿用项目自动保存。
- 外部接入权限独立于应用内 Agent 自动模式。应用内 ACP/Pi 及现有项目/论文工具不受此改动替代。
- `render_canvas_preview` 返回真实 TeX PNG 预览，可检查当前图和最近提案；每份新源码草稿有独立的渲染预算与缓存。
- `get_canvas_source` 返回访问模式与最近提案状态，外部 Agent 可观察审核结果并继续修改，无须每次重建连接。

## 授权、版本与生命周期

- 连接绑定用户明确授权的窗口、项目和画布；所有写操作校验最新 `revision` 和 `sourceHash`，拒绝过期或并发覆盖。
- 关闭连接、关闭工具总开关、切换项目/画布或退出应用后撤销授权；重新开启需复制新配置并重连。
- 只监听本机回环随机端口，连接令牌不由应用持久化。私有 `/call` 桥接不是可直接配置的 HTTP MCP endpoint。
- 处理连接启动期间的取消与替换，避免旧连接的延迟清理关闭新连接；断开后的异步读取或渲染结果不再回填。

## 当前边界

- 外部入口仅开放绘图工具，不提供论文文件、任意文件读写、Shell、画布文件创建/删除或导出工具。在 UI 选定或新建画布后，可通过 MCP 从空白画布绘图。
- 本版本不提供公网/局域网远程控制、公开 HTTP MCP 入口或跨重启稳定授权。
- 配置包含临时访问令牌，只应交给受信任的本机客户端。TeX 渲染沿用本机编译器及项目资源访问权限，不是文件系统安全沙盒。
- 已应用到编辑器不等于已保存到磁盘；编译成功也不代表已完成视觉确认。断开连接清除未应用草稿，保留已经应用的修改。
- 跨平台安装包、Web 静态包及 SHA-256 校验码由 GitHub Actions 验证、构建后发布。

使用说明见仓库的 `docs/mcp-guide.zh-CN.md`。
