# AgenTikZ v0.10.0

## 绘图 Agent 草图参考

- Agent 输入框新增手绘草图入口。空白画布可用于表达新图的布局、分组和箭头走向。
- 可在当前图的精确 TeX 预览上直接圈画和标记；预览作为只读底图，与标注合成单张 PNG。
- 支持画笔、橡皮擦、撤销和清空，并沿用现有 PNG 图片附件、缩放和图片能力校验。
- 草图作为当前消息图片附件传给 ACP 或 Pi；不保存为项目资产、不修改 TikZ 源码。论文工作区不显示草图入口。

## 工作区

- 启动时自动恢复上次项目后，直接进入绘图工作区，不再因项目包含论文而切到论文工作区。

## 验证与发布内容

- 增加绘制路径、图层合成和参考图等比适配的单元测试。
- 通过完整 Vitest 单元测试与 TypeScript / Vite 生产构建。
- Windows、macOS、Linux 安装包及 Web 静态包由 GitHub Actions 构建发布，并提供 `SHA256SUMS.txt`。
