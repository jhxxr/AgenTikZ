# AgenTikZ v0.7.1

## Windows Pi 启动修复

- 修复 Windows 桌面端传入规范化资源路径（`\\?\C:\...`）时，Node.js 加载 Pi worker 失败并直接退出的问题。该故障会同时影响 Pi 运行时检测、渠道模型获取和聊天请求。
- 在启动边界规范化 Node 可执行文件、worker 入口和工作目录路径，复用现有 ACP 路径处理，保留 UNC 网络路径语义。
- 改进错误提示：区分 worker 尚未就绪时的启动失败与运行中退出，并报告安全的退出码；不回显可能包含密钥或项目内容的 stderr。

## 回归验证

- 新增真实 worker 的 Windows 规范化路径回归测试：修复前复现“Pi 进程已退出”，修复后正常启动并读取模型目录。
- 通过桌面后端的真实 worker 协议测试模型获取成功、HTTP 404 返回渠道错误，以及错误后同一进程仍可继续读取模型目录。
- 本地完整 Rust 回归 42 项通过；Pi JavaScript 测试 21 项通过。
- 实际 Windows 桌面界面点击“检测 Pi 运行时”后，确认 Pi SDK v1.5.0 握手通过、运行时与模型目录已就绪。

## 使用边界

- 保留 v0.7.0 的 Pi 多渠道管理、独立系统凭据和 ACP 模型选择功能；未调整渠道配置或密钥。
- 获取模型列表不代表实际推理请求成功；真实渠道地址、密钥及协议兼容性仍需按供应商规格配置。本次验证未调用付费模型。
- 桌面端仍需本机 Node.js 22.19+；更新安装包后需重启应用，旧二进制不包含该修复。

Windows、Linux、macOS 安装包、Web 静态包与 `SHA256SUMS.txt` 由 GitHub Actions 完成验证和构建后发布。
